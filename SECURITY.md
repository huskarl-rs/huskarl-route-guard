# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/huskarl-rs/huskarl-route-guard/security/advisories/new)
(the "Report a vulnerability" button). This is our preferred reporting channel.
Alternatively, email [gary@lyranthe.org](mailto:gary@lyranthe.org).

Please do not open a public issue containing vulnerability details.

Include whatever information you have:

- Affected crate version or commit.
- A minimal reproduction, including route registrations and guard configuration.
- The request path and HTTP method.
- Downstream server or proxy configuration, if relevant.
- Expected behavior, observed behavior, and potential impact.

Incomplete reports are welcome.

We will investigate and coordinate disclosure with you. Please allow time
for assessment and a fix before publishing vulnerability details.

## Supported versions

Security fixes target the latest published release. Older releases
are not maintained separately.
